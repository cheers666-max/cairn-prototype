## 标题

```
手机不是通知太多，是"位置"不对
```

## 正文

```
在做一台墨水屏的小设备，只做一件事：把 AI agent 需要你拍板的决定，放在桌面上一个固定位置。

做之前我们先去查了一件事：墨水屏到底是不是更专注？

结论有点意外——

墨水屏本身并不等于专注。
真正起作用的东西，1995 年就有名字了：calm technology（平静的技术）。

Xerox PARC 的 Mark Weiser 是这么定义的：
「平静的技术会在注意力的外围和中心之间，轻松来回移动。」

外围 = 我们被调谐到、但不明确注视的东西。

挂在墙上的钟就是外围。你看一眼就知道几点，不需要"处理"它。
而手机锁屏不是——每一条通知都在要求你移到中心。

所以真正的问题不是"通知太多"，
是手机把一切都推到了中心。

我们想让 agent 的决定回到外围：
卡片待在一个固定的地方，不亮、不响、不弹窗。
你什么时候走过去看，由你决定。

—

说点对我们不利的。

我们查了眼疲劳那批文献，墨水屏并没有被证明能提升专注。
Benedetto 2013 确实发现墨水屏≈纸质、LCD 更累，但那测的是连续读散文一两小时；
Siegenthaler 2012 的结论更狠——关键是图像质量，不是显示技术；
而且没有任何研究接近"全天工作"这个场景。

所以「墨水屏护眼」我们不拿来当论据。

如果大家根本不需要第二块屏，这东西就不该存在。
这也是我们做原型求反馈的原因——说"我不需要"同样是有价值的答案。

—

现在它是个 USB 样机，软件部分能跑（图里那三张卡是真的）。独立联网、电池、磁吸都还没做。

想问你：平时有没有用某个"固定位置的东西"来处理这类等待？便利贴、便签屏、第二块显示器、手表？

评论区聊聊就行。
```
