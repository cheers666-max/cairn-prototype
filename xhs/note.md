## 正文

```
用上 Claude Code / Cursor 之后，工作流里多了一种新型的累：
不是写代码累，是「等」累。

Agent 在后台跑任务，你切出去看文档，又怕它随时卡住要权限；
开了桌面通知或手机推送，每一声「叮」都在把心流撕碎。

我们在做一台桌面墨水屏小设备（Cairn），只干一件事：
把 AI Agent 需要你拍板的瞬间，从「弹窗」移到桌角一个固定位置。

—

动手前，我们先查了一遍人机交互与认知文献。结论挺反直觉：

墨水屏本身，并不等于专注。
真正起作用的机制，1995 年就被 Xerox PARC 首席科学家 Mark Weiser 命名了：Calm Technology（平静的技术）。

Weiser 把注意力分成「中心」与「外围（Periphery）」。
墙上的挂钟就是典型的「外围」——它一直在那，余光扫一眼就知道几点，平时绝不拽你。
而手机锁屏和电脑通知栏却在失控：不管事情大小，每条通知都在强行索要你的「中心注意力」。

所以，真正让人疲惫的不是「通知太多」，而是「位置不对」。

我们想把 Agent 的状态交接放回「外围」：
· 卡片永远待在桌角固定坐标，不亮、不响、不弹窗
· 只呈现 3 种边界：跑完了 / 卡住了 / 要你批准
什么时候转头看它，主动权在你。

—

也说点对我们不利的实话：

很多墨水屏硬件主打「护眼、提升专注」，但翻完眼疲劳文献会发现站不住脚：
1. Benedetto (2013) 测出 E-Ink 比 LCD 视疲劳低，但场景是「连续读散文一两小时」，并非高频切换的全天工作流；
2. Siegenthaler (2012) 结论更狠：决定阅读体验的是图像质量，而非显示技术。

所以我们定下规矩：绝不拿「墨水屏护眼」当论据。如果大家不需要第二块物理屏，它就不该存在。

—

目前它只是台 USB 早期样机，软件卡片已跑通（图2那三张卡是真的），独立联网、电池、磁吸还没做，也没定价格和上市时间。

想听听各位的真实工作流：
后台挂着 AI 或长任务时，你靠什么处理等待？便利贴、副屏、手表，还是觉得现有通知就够用了？

哪怕一句「手机就够了，没必要」，对我们也是极有价值的答案。评论区直接聊。
```
