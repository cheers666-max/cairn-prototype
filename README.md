# Cairn — 决策卡片原型 · 反馈页

这是 Cairn（一台 AI 墨水屏个人助理）原型阶段的**单页反馈收集站**。

**页面本体**：<https://cheers666-max.github.io/cairn-prototype/>

给 AI coding agent 用户看的三张「决策卡片」——跑完了 / 卡住了 / 要你批准——以及一张
3 分钟就能填完的反馈表。

## 这是什么，不是什么

先说清楚边界，免得你按想象回答：

- 这是 **USB 开发样机**的软件侧演示：**需要连一台电脑**，页面里的卡片是软件渲染的，**不是实体墨水屏刷新画面**。
- **独立联网、电池、磁吸结构都还没做**。整机厚度未量测，**7.5mm 是设计目标值，不是已达成参数**。
- **录音 / 语音转文字未实现**；**不运行 Android、不能装 App**。
- **没有价格、没有上市时间、没有订阅计划**。这一轮只问设备本身值不值得买。

如果你觉得「手机通知已经够用了，不需要这个」——**那正是我们在找的答案**。
页面的第 6 题专门留给这个立场，请直接选、直接写。

## 反馈怎么走

页面**没有任何后端**，不收集、不上传任何数据。填完之后走三条路，你自己选：

1. **复制全文** → 粘到邮件、帖子或任何你方便的地方
2. **用邮件发送** → 打开你本机的邮件客户端，正文已预填
3. **下载为文件** → 存成 `cairn-feedback.md`

## 仓库结构

```
index.html            # 构建产物：自包含单文件（图片/视频全部内嵌 base64）
                      # ↑ GitHub Pages 直接服务这个文件
site/template.html    # 源模板
build.py              # 把 assets/ 内嵌进模板，产出 index.html
assets/               # 卡片图（网页版 + 墨水屏位图版，中英各一套）+ 60 秒演示视频
dist/                 # 本地构建输出（与根目录 index.html 同物）
```

重建：

```sh
python3 build.py     # → dist/index.html
```

## 为什么做成单文件

页面要同时给中文和英文受众看，而这两个渠道的海外可达性差别很大（中文侧走国内对象存储，
英文侧走 GitHub Pages）。做成自包含单文件之后，同一份产物可以丢到任何地方——对象存储、
静态托管、邮件附件——不会出现「只传了 HTML 没传 assets」导致图片全裂的经典事故。

## 页面里那张 800×480 的位图是什么

「墨水屏位图版」是真正会发到墨水屏上的那 48000 字节画面（1-bit）。
它说明这些卡片**能**画到硬件上，但**硬件本身仍未点亮**。
